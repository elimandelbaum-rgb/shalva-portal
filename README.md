# פורטל עובדים שלוה 🟣

מערכת ניהול עובדים מלאה — פרונטאנד (`public/index.html`) מחובר לשרת **Express** ולמסד נתונים **SQLite**.
כל קריאות ה‑API בדף (`/api/...`) מחוברות אוטומטית לשרת. בהרצה ראשונה מסד הנתונים נבנה ומאוכלס לבד (משתמשים, מחלקות, טפסים, כתבות, הודעות ופרסומות לדוגמה).

---

## 🚀 הרצה מקומית (3 צעדים)

דרוש **Node.js 18 ומעלה** מותקן במחשב.

```bash
# 1. התקנת חבילות
npm install

# 2. (אופציונלי) הגדרת משתני סביבה
cp .env.example .env      # ואז ערוך את .env

# 3. הרצה
npm start
```

השרת יעלה על **http://localhost:3000** — פותחים בדפדפן.

| תפקיד | שם משתמש | סיסמה |
|---|---|---|
| מנהל מערכת ראשי | `admin` | `admin123` |

| מנהלת תפעול | `מיכל` | `1234` |
| מנהל שכר | `יוסי` | `1234` |

הכניסה לאזור הניהול היא דרך אותו מסך כניסה — לפי התפקיד נפתחות ההרשאות המתאימות (דשבורד, ניהול עובדים, בונה טפסים, רולר הודעות, פרסומות, שלומית AI, הגדרות ועוד).

## 🗂️ מבנה התיקיות

```
shalva-portal/
├── server.js          ← שרת Express + כל ה‑API
├── db.js              ← הגדרת SQLite + אכלוס ראשוני
├── package.json       ← תלויות וסקריפט הרצה
├── .env.example       ← תבנית משתני סביבה
├── public/
│   ├── index.html     ← הפרונטאנד (מוגש ע"י השרת)
│   ├── logo.png       ← (אופציונלי) הלוגו שלך
│   └── media/
│       ├── sha.mp4         ← (אופציונלי) סרטון התדמית לקרוסלה
│       └── sha_poster.jpg  ← (אופציונלי) תמונת פוסטר לסרטון
├── data/              ← נוצר אוטומטית — קובץ ה‑SQLite (shalva.db)
└── public/uploads/    ← נוצר אוטומטית — קבצים שמעלים דרך ספריית המדיה
```

> **הערה:** `logo.png` והסרטון `media/sha.mp4` הם אופציונליים. בלעדיהם המערכת עובדת מצוין — הלוגו נופל חזרה לטקסט "שלוה", והקרוסלה מציגה את שאר הפרסומות. פשוט הפילו את הקבצים שלכם לתיקיות הנ"ל.

## ⚙️ משתני סביבה (`.env`)

| משתנה | תיאור |
|---|---|
| `PORT` | פורט השרת (ברירת מחדל 3000) |
| `SESSION_SECRET` | מחרוזת סודית לסשן — החליפו לערך אקראי בפרודקשן |
| `ANTHROPIC_API_KEY` | מפעיל את הצ'אט "שלומית AI". בלעדיו הצ'אט מחזיר הודעה מנומסת שהמפתח לא הוגדר |

---

## ☁️ העלאה לאוויר (Railway / Render / VPS)

1. העלו את התיקייה לגיט (יש `.gitignore` מוכן — `node_modules`, `data`, `.env` מוחרגים).
2. הגדירו את משתני הסביבה בפאנל השירות (`SESSION_SECRET`, `ANTHROPIC_API_KEY`).
3. פקודת ההפעלה: `npm start`. השירות יזהה את הפורט מ‑`process.env.PORT` אוטומטית.

> `better-sqlite3` שומר קובץ מקומי — לפרודקשן עם דיסק חולף (ephemeral) חברו **דיסק קבוע (Volume)** לנתיב `data/` כדי לא לאבד נתונים.

## 📧 מיילים (אופציונלי)

שליחת מייל ל‑HR בכל פנייה חדשה עובדת אם ממלאים `smtp_user` + `smtp_pass` במסך **הגדרות** (וקיים `nodemailer`). בלי הגדרה — הפנייה נשמרת כרגיל והמייל נרשם ל‑log בלבד.
